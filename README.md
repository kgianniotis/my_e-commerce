# My E-Commerce

## About
**My E-Commerce** is a project which presents modern eshop design and user friendly cloth displays.

## Features
- Search Bar
- Marquee Banner
- Section with items on sale
- Catalog with every item
- JSON file with products from the Kaggle database

## Technologies Used
- React
- Javascript
- Node

## How to Run
1. Download or Clone the repository
2. Navigate to the project root
3. Run 'npm install' to install dependencies
4. Run 'npm dev run' to launch the project
